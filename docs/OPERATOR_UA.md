# FALSICORE — запуск без розпакування

Один файл `falsicore.pyz`, Linux, Python 3.10+. Спочатку звірити опублікований
SHA-256, потім запускати як звичайний користувач:

```bash
python3 -I /повний/шлях/falsicore.pyz
```

Відкрий локальний `dashboard.html` за адресою, яку покаже програма. Усередині —
знахідки, пояснення, обмеження, доступні метадані та рекомендовані дії.
Картки знахідок розкриваються без JavaScript і без зовнішніх ресурсів.
`PARTIAL` — обмеження спостереження. `FAILED` — збій колектора. Це різні речі.
Нуль індикаторів — не гарантія відсутності злому.

Додаткові команди: `verify-app`, `self-test`, `scan --profile quick`,
`verify /шлях/до/звіту`, `explain /шлях/до/звіту`.
Самотестування створює тимчасову приватну копію коду й автоматично прибирає її.
Деякі негативні тести навмисно генерують повідомлення про відхилений файл;
підсумок `OK` означає, що очікувані відмови перевірено.

Не надсилай `private_index.json`, конфігурації, cookies або сирі журнали в чат.
Сканер нічого не лікує автоматично, не змінює `.bashrc`, не встановлює пакети,
не видаляє попередні версії та звіти й не підвищує привілеї самостійно.

Для GitHub джерела вже всередині: `export-source "$HOME/falsicore-source"`.
Цільовий каталог має бути новим. Встановлення таймера — лише окрема свідома дія
в експортованому стабільному каталозі, не в Downloads.
